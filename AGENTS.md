# Project instructions

## NPC conversation layout — user-approved and fixed

Before creating or changing any character conversation screen, read `docs/npc-dialogue-design.md`, especially the final V157 approval and locked measurements. Reuse the approved measurements in `circus-dialogue-v152.css` and shared theme `npc-dialogue-v153.css`.

The user explicitly requires the same dialogue sizes and positions in every character conversation. Change character art and conversation text, not typography, panel size, screen position, spacing or palette. Never invent a new layout or zoom the approved scene again. Background fills the entire viewport without an inset modal. Landscape: question left, three compact answer rows right at the bottom. Preserve the documented portrait adaptation consistently. Any requested visual redesign must first be previewed and approved by the user.
