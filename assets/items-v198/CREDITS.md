# Shield inventory icons — V198

Six separate 320 × 320 transparent WebP icons, rendered from the corresponding optimized models with warm key lighting, cool fill and a studio reflection environment. No marketplace photograph, thumbnail or character screenshot is used. The icons preserve the selected shields' original colors and motifs. Each icon is below 25,000 bytes.

Source authors and licenses: [equipment credits](../equipment-v198/CREDITS.md). All processing, including the noAI-licensed CGTrader shield, is conventional 3D rendering and image encoding. No generative AI tool was used.

Rebuild deliberately with `LUDUS_REBUILD_SHIELD_ICONS=1 node scripts/render-shields-v198.cjs`. Routine visual verification does not overwrite shipped icons.
