# Existing equipment, optimized for V190

These resources are derived from the existing user-supplied models in this
repository: `roman_scutum_shield.glb`, `roman_shield.glb`, `roman_spatha.glb`.
The original geometry, artwork, material factors and original attribution
metadata are retained. Original source files are unchanged in the repository.

Offline processing: texture resizing and WebP encoding, joining compatible
rigid pieces, vertex welding and quantization. No generative imagery, new
model source or replacement artwork was used. This note does not grant new
rights to the original assets. Source and output hashes are in
`build-report.json`; reproduction is documented in
`scripts/pack-classic-equipment-v190.mjs`.
