# Realistic inventory artwork — V197

Four independently generated, transparent inventory illustrations replace the direct model renders from V196. Style references were the game's existing `assets/items-v119/trident.webp` and `assets/items-v119/manica.webp`: realistic materials, a clear isolated silhouette, and consistent lighting. Descriptions requested respectively a three-pronged steel trident with a wooden shaft, segmented steel arm armour, lion-motif shoulder and arm armour, and a buckled leather forearm guard.

No source model, source texture, source photograph, source screenshot, or render of the NoAI-tagged Sketchfab Gladiator was submitted for generation. These icons are illustrative inventory art; the 3D models retain their separate author credits and source textures. Each delivered icon is a 320 × 320 WebP with transparency, under 20 KB. Game cards load these files through the shared production icon lookup.

The historical V196 icon render script now writes shipped icons only when explicitly invoked with `LUDUS_REBUILD_V196_ICONS=1`; ordinary visual tests do not overwrite artwork.
