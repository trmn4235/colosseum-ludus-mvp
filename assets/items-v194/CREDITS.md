# Helmet icons — V194

These four icons are direct Three.js renders of the existing helmet geometry and embedded textures used by the game. No independent illustration or substitute design is used.

- `helmet-gold.webp`: `assets/equipment/gladiator-9bcb0ac9d566.glb`, originally supplied as `gladiator_helmet.glb`.
- `helmet-silver.webp`: `assets/equipment/knights-e30cc69af0fd.glb`, originally supplied as `knights_helm.glb`.
- `helmet-winged.webp`: `assets/equipment/winged-111637d14990.glb`, originally supplied as `winged_helmet_gameready.glb`.
- `helmet-roman.webp`: `assets/equipment/roman-6d187d4b7f8c.glb`, the existing Roma helmet.

Underlying model and texture attribution remains with the original assets and their authors. This change does not introduce or alter their licensing. See the existing repository asset credits and `source-audit.json` for source identity verification.

Reproduction: `scripts/render-helmet-icons-v194.cjs`. Output dimensions are 512×512 with transparent backgrounds. Geometry and render counts are recorded in `render-report.json`.
