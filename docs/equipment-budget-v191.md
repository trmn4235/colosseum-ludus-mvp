# V191 — lighter visor helmet, greaves and courtyard icons

All sizes use decimal bytes. The changes are wired into all five character renderers and both dynamic caravan/pit loaders. Versioned asset and script URLs avoid reusing cached V190/V189 resources.

| Active resource | Before | After | Reduction |
| --- | ---: | ---: | ---: |
| Visor helmet download | 4,824,976 B | 434,936 B | 90.99% |
| Helmet triangles | 11,674 | 6,652 | 43.02% |
| Helmet colour-pass draw calls | 3 | 1 | 66.67% |
| Helmet RGBA texture budget, with mipmaps | 21.33 MiB | 3.33 MiB | 84.38% |
| Two courtyard mace icons | 1,508,290 B | 59,902 B | 96.03% |
| Greave pair triangles | 5,096 | 2,312 | 54.63% |
| Shared greave vertex/index buffers | 72,184 B | 37,272 B | 48.37% |

The two shields already load the V190 resources: 204,436 B and 179,768 B. Their 512/256 px texture budgets remain 3 MiB each instead of 16 MiB. V191 browser checks confirm no original multi-megabyte shield is requested.

The helmet retains the source materials and normal/specular details. Offline simplification locks topology borders, joins its rigid parts and quantizes attributes. The existing GLTF loader decodes WebP directly; no new runtime decoder. The build report records source/final hashes, exact sizes and image dimensions. The source helmet remains for provenance and visual regression and is not loaded by the game.

Greaves are generated by the game and have no separate mesh download. Only shell/rim/rivet subdivisions changed. Shape, straps, proportions, skeletal fitting and template sharing remain. For 20 fighters wearing these greaves, the colour pass draws 55,680 fewer triangles; shadows can benefit as well. This is a geometric workload reduction, not an FPS measurement.

The approved transparent mace photographs retain their framing. Both 1254 px PNGs become 512 px WebP images; no new art or UI layout. Their combined decoded RGBA images decrease from 12,580,128 B to 2,097,152 B (83.33%).

## Validation

- Seven V191 asset, cache and five-rig attachment checks; twelve helmet/catalog regressions; nineteen existing shield/helmet/equipment checks passed locally.
- Actual browser WebP decoding, one helmet request for 20 concurrent load calls, shared geometry/materials, and versioned shield requests passed.
- Eight before/after close-up comparisons: helmet silhouette overlap at least 99.95%; greaves at least 99.30%. Worst mean colour error was 2.30%. Twenty-one screenshots include five worn combat poses and were visually reviewed.
- The actual courtyard weapon-selection UI, map return and exhibition run passed at 932×430, 667×375 and 390×844. All four mace images decode from V191 URLs; no missing scene assets or script errors.
- Existing transform-cache tests passed for five renderers, 324 frames each, with no pose changes and elapsed-time checks at 10–120 Hz.
- CI runs the V191 browser comparison in Chromium and WebKit. A physical iPhone FPS measurement has not been made.

Rebuild with `node scripts/pack-equipment-v191.mjs`; dependencies and versions are in the script header. AES-GCM generates a fresh nonce when repacking, so encrypted file hashes change on each rebuild; geometry, images and byte budgets are tested independently.
